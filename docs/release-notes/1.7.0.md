## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.25.

### What's new since 1.6.1
- Added: saved printers in the quick-switch dropdown can now be given a nickname (e.g. "Main RPi4" / "pi400 test") with the new **Name** button, instead of only showing the raw IP.
- Added: the Klipper fault banner now also shows when the print itself reports state **error**, not just a Klipper shutdown.
- Added: three new **Printer** buttons - **Restart Klipper**, **Restart firmware** and **Emergency stop** - that call Moonraker's dedicated endpoints directly, so they work even while Klipper is in an error state.

See CHANGELOG.md for the full list per version.
