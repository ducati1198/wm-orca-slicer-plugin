## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.28.

### What's new since 1.7.2
- Changed: the Dryer card's duration input dropped the separate Minutes box - it's now Hour only (whole hours, 0-12), matching the Temp box's layout.

See CHANGELOG.md for the full list per version.
