## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.18.

### What's new since 1.3.0
- Fixed: the **Screen live-refresh helper** card could show up on a **vanilla (upstream) Klipper** printer, not just factory printers. A vanilla Klipper + Fluidd setup keeps a `tmt1.ini` file too (for the same colour/material swatches), so its existence alone no longer decides whether the card shows - the plugin now also checks for the vanilla installer's `_ZR_SET_TOOL_INFO` macro, the same signal it already uses elsewhere to tell factory and vanilla printers apart.

See CHANGELOG.md for the full list per version.
