## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.17.

### What's new since 1.2.0
- **One-click installer for the live screen refresh helper:** on a factory printer where the optional `wm-screen-sync-http` helper is not detected, the Device tab now shows a **Screen live-refresh helper** card with an **Install helper on printer** button (macOS/Linux builds of Orca). Press it, confirm the warning popup, keep or edit the pre-filled factory default login, and the plugin installs the helper over SSH for you - no terminal needed. See the README's "Factory printers: live screen refresh" section.
- Fixed a crash in the Light button when the helper's status check failed.
- Fixed the helper card sometimes staying invisible even when it should show.
- Fixed the installer itself crashing OrcaSlicer on macOS, and a follow-up permission denial from Orca's plugin sandbox - the installer now authenticates over SSH without forking the host process, and writes its one-time helper script inside the plugin's own data folder.

See CHANGELOG.md for the full list per version.
