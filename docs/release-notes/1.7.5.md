## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.30.

### What's new since 1.7.4
- Fixed: a printer's nickname disappeared from the dropdown every time you switched printers, reconnected, or reopened Orca - the everyday cause of names not sticking. 1.7.4 fixed a narrower case (a name surviving a plugin update); this is the main fix.

See CHANGELOG.md for the full list per version.
