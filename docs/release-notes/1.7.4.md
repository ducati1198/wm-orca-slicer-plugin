## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.29.

### What's new since 1.7.3
- Fixed: a printer's nickname (the Name button) could disappear after a plugin update. Nicknames are now saved in two folders and merged on read, the same way the known-printer list already was, so a name survives a plugin update.

See CHANGELOG.md for the full list per version.
