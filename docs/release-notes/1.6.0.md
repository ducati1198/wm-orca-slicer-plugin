## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.23.

### What's new since 1.5.0
- Fixed: the ACE Pro **Dryer** card could show `-` for Status and Time left even while the dryer was actively running, on firmware that reports that block as `dryer_status` instead of `dryer`. The plugin now checks both names, same as the driver's own console command already does.
- Changed: the Dryer card's run-duration input is now separate **Hours** and **Minutes** fields instead of one "Minutes" box.
- Fixed: the Dryer card's "Time left" showed minutes mislabelled as hours (the ACE driver reports `remain_time` in seconds, not minutes) - now formats correctly, e.g. "1h 30min".
- Fixed: the WM Device tab's own **Printing Progress** percentage could read very differently from Fluidd's on the same file. It now uses the same calculation Fluidd's default "File" progress mode uses, instead of a different, time-based estimate.
- Added: the Printing Progress panel now also shows **Speed**, **Flow**, **Filament** used and **Layer**, matching OrcaSlicer's own native Device tab layout.
- Added an offline self-test suite extension covering all of the above.

See CHANGELOG.md for the full list per version.
