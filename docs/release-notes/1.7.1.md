## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.26.

### What's new since 1.7.0
- Changed: PA nozzle temperature default is now 260 C (previously 270), matching a printer-side material table update. Only PA itself moved - PA-CF and PA-GF stay at 280.

See CHANGELOG.md for the full list per version.
