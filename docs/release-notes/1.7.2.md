## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.27.

### What's new since 1.7.1
- Fixed: the "Install helper on printer" button's SSH step no longer copies the whole process environment into the `ssh` subprocess - only `PATH`, `HOME` and the `SSH_ASKPASS` variables it needs. Addresses the Medium-risk "reads environment variables" item from Orca Cloud's security review. No behaviour change.

See CHANGELOG.md for the full list per version.
