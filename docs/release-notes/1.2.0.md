## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.1.

### Everything the plugin does
- **WM Device tab** with Status, Files, History, Timelapse and Messages pages for a Moonraker printer
- **Live status:** state, active nozzle, bed and chamber temperatures with trend graphs, position, homed axes, fans, speed factor
- **Four toolheads:** spool colour and material (drawn as small spools), edit a spool and save it to the printer, **tangle indicator** (grey normally, red TANGLE when the hub sensor triggers)
- **Print progress and camera:** progress ring, Pause, Resume, Stop (asks first); the camera fits its picture with no black bars
- **Controls:** temperatures, fans, speed factor, move panel, light, Home Z, Motors off, cool down, and the **Unload Menu** button
- **Printer popup windows** from macros open inside the tab
- **Files:** part pictures, filament colours and weight, Print with the tool mapping window first, tick boxes and Delete
- **History:** last 25 prints with pictures, colours, totals bar, Print again, tick boxes and Delete
- **Timelapse:** list the printer's timelapse videos with previews, Play in the tab, Download, Delete
- **ACE Pro panel** when the printer has one: slots, drying, endless spool
- **WM Tool Map slicing step:** shows the filaments of the file and the four toolheads and writes your choice into the G-code; the map is remembered per project and warns when a filament does not match
- **Print notices** when a print ends, pauses or fails
- **Remembers your printer** after Orca restarts, also on Windows
