## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.24.

### What's new since 1.6.0
- Changed: PLA nozzle temperature default is now 220 C for all PLA types (PLA, PLA Silk, PLA Matte, PLA Metal, PLA+, PLA-CF), matching the printer-side material table. Only affects the suggested value the Spool editor pre-fills when you pick a PLA material - no macro names, arguments or material numbers changed.

See CHANGELOG.md for the full list per version.
