## WM Device for OrcaSlicer 2.5.2 (WonderMaker ZR Ultra / Ultra-S)

Install: download `wm_device.py` below, then in OrcaSlicer use File > Plugins > Install local plugin. Full guide and pictures are in the README. The file inside is plugin build 0.29.21.

### What's new since 1.4.0
- Fixed: the **WM Tool Map** window's warning text numbered toolheads one higher than the toolhead buttons themselves - a warning could say "toolhead 2" about the exact same toolhead its own button labelled "T1". Warning text now always matches the button labels (T0 to T3).
- Fixed: the **Light** button's colour didn't reflect the chamber light's real on/off state on printers using a `WM_CHAMBER_LIGHT` Klipper macro (the vanilla Klipper setup). It now reads and sets the light's real state straight over Moonraker's own `device_power` API, no extra helper needed, and turns green while the light is on there too.
- Fixed: the **WM Tool Map** window listed, warned about and asked you to map every filament configured in the Orca project, even ones the current print doesn't use at all. It now only shows the filaments the slice actually used; an unused slot is never removed from the underlying toolhead map, so the G-code's toolhead numbers stay correctly aligned either way.
- Added an offline self-test suite (`tests/`) covering all three fixes above, so a future change to this logic can be checked without a real printer.

See CHANGELOG.md for the full list per version.
